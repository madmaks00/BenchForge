# Иконки BenchForge

Исходное изображение знака BenchForge хранится в `Source/benchforge-original.png`. Версия `benchforge.png` используется в шапке окна. Файл `benchforge.ico` содержит кадры системного значка от 16 до 256 пикселей.

Логотипы PostgreSQL, MySQL, MariaDB, MongoDB, Redis, ClickHouse и SQLite взяты из [Devicon](https://github.com/devicons/devicon). Для PNG MySQL и MariaDB использованы светлые оттенки для тёмного фона. Лицензия коллекции находится в `DEVICON-LICENSE.txt`.

Знак Valkey взят из [репозитория графических материалов Valkey](https://github.com/valkey-io/assets/tree/main/Valkey%20Branding/logo%20svgs).

Знаки СУБД используются для обозначения продуктов и принадлежат своим правообладателям.
